# Código de Conduta

Esperamos que todas as pessoas participantes tratem umas às outras com respeito,
boa-fé e profissionalismo.

Não são aceitos assédio, discriminação, ameaças, ataques pessoais, publicação de
dados privados, conteúdo sexual indesejado ou comportamento que prejudique a
segurança da comunidade.

Mantenedores podem remover conteúdo ou restringir a participação quando necessário
para manter um ambiente seguro. Para relatar um problema, abra uma issue privada
para os mantenedores ou use o canal de segurança descrito em [Security.md](Security.md)
quando houver risco de segurança.
