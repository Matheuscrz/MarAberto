# ADR-008: Retenção configurável por instalação

- Status: Aceito (2026-11-06)
- Contexto: prazos de retenção dependem do órgão operador, finalidade, legislação aplicável e orientação jurídica.
- Decisão: tornar a retenção configurável por instalação, usando 5 anos como padrão provisório para auditoria até validação jurídica.
- Alternativas: fixar 5 anos no produto; deixar a retenção sem qualquer padrão.
- Consequências: cada instalação pode cumprir sua política; a configuração, os jobs de expurgo e as exceções de auditoria precisam ser auditáveis.
