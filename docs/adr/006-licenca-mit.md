# ADR-006: Manter licença MIT

- Status: Aceito (2026-11-06)
- Contexto: o repositório já contém uma licença MIT, e o projeto busca adoção por órgãos e colaboradores diversos.
- Decisão: manter MIT para o código do projeto. Conteúdo e dados podem ter licenças próprias, sempre documentadas.
- Alternativas: Apache-2.0; AGPL-3.0.
- Consequências: baixa barreira de adoção e permissões amplas; forks proprietários são permitidos e contribuições continuam dependendo da colaboração da comunidade.
